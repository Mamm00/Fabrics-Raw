AL AZHAR TEX / الأزهر تكس — GITHUB ACTIONS SECRET INVENTORY
=======================================================
Names only. No values are stored here; GitHub Actions secrets are write-only.

Signing (CI builds only):
  ANDROID_KEYSTORE_BASE64
  ANDROID_KEYSTORE_PASSWORD
  ANDROID_KEY_ALIAS
  ANDROID_KEY_PASSWORD

Backend host environment (never in APK / Actions / Pages):
  BENCHMARK_PROVIDER_URL
  BENCHMARK_API_KEY

Not secret:
  BACKEND_BASE_URL, VAT/wastage defaults, keystore file (gitignored)

Leak check:
  git ls-files | grep -Ei 'jks|keystore.properties|\.env$|local.properties'   # expect empty

Prefer a CI-only keystore, or local signing. Anyone able to edit a workflow
can exfiltrate a production keystore stored in Actions secrets.
